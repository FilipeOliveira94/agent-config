How the numbers are counted

Clean merge
Merged with no commit written after the PR was up for review and no feedback round logged.
Merge rate
Merged PRs out of merged plus closed-without-merging PRs.
Rework commits
Commits written after the PR was up for review (a draft: after it was marked ready): review fixes, CI fixes, conflict merges. Counted by author date, so a rebase alone adds none.
Questions
Stops for you outside the planned plan-approval gate, logged with change-ledger log ask. Per change counts only changes agents started in the ledger.
Expected/Seen
The ledger's rating for the change, else the issue's rating in the roadmap on the default branch. - is a half not filled yet.
Code lines
Lines added outside docs, lockfiles, generated files and binaries. Measured size: Sm up to 400, Md up to 1,000, Lg above (the scale in workflow.md).
Stale
A PR open for more than hours.
